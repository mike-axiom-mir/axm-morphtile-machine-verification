# Licensing boundary

MorphTile separates the workshop from what people build in it.

## The model

| Layer | Default permission |
|---|---|
| A tile or asset created in MorphTile | Portable Creator Output; the creator chooses its licence. |
| A combined game, website, world, or application | Portable Creator Output; it may be exported, edited elsewhere, shared, or sold. |
| MorphTile engine and workshop | PolyForm Noncommercial 1.0.0: noncommercial use, modification, and redistribution are allowed. |
| Commercial use of MorphTile to make Creator Output | Allowed by `CREATOR_OUTPUT_PERMISSION.md`. |
| Selling, hosting, monetizing, bundling, or commercially redistributing MorphTile itself | Requires separate written permission after a grounded use case is presented. |

## What “no lock” means

A creation is matter, not a hostage of the workshop. Exported Creator Output
must be able to leave MorphTile without MorphTile claiming ownership or forcing
the engine's noncommercial terms onto the creation.

An export should therefore use open, inspectable formats and avoid embedding
the MorphTile engine. If an export later needs a MorphTile runtime component,
that component needs its own explicit redistributable licence. No runtime right
is silently implied.

This boundary does not erase copyrights, trademarks, patents, licences, or
other rights in third-party material included by a creator.

## The shortest version

> Earning with MorphTile is permitted. Earning from MorphTile requires a
> grounded case and separate written permission.

The legally operative files are `LICENSE` and
`CREATOR_OUTPUT_PERMISSION.md`. This page is a plain-language explanation.
