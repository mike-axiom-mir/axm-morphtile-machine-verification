# Licensing boundary

This creation machine separates its software from what people build with it.

| Layer | Default permission |
| --- | --- |
| Candidate or exported Creator Output | Portable output; the creator chooses its licence. |
| A combined asset, game, website, world, or application | Creator Output; it may be exported, edited elsewhere, shared, or sold. |
| This creation machine | PolyForm Noncommercial 1.0.0: noncommercial use, modification, and redistribution are allowed. |
| Commercial use of this machine to make Creator Output | Allowed by `CREATOR_OUTPUT_PERMISSION.md`. |
| Selling, hosting, monetizing, bundling, or commercially redistributing this machine itself | Requires separate written permission after a grounded use case is presented. |

“No lock” means the output is not a hostage of the machine. An export should use inspectable formats and avoid embedding the machine runtime. If an export needs runtime code, that code needs an explicit redistributable licence; no runtime right is silently implied.

This boundary does not erase third-party rights. The legally operative files are `LICENSE` and `CREATOR_OUTPUT_PERMISSION.md`.

> Earning with the machine is permitted. Earning from the machine requires a grounded case and separate written permission.
